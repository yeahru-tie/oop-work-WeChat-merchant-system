在仓库根目录，推荐通过一次性入口使用，不要求手工配置系统环境：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\maven.ps1 --version
```

上面的执行策略仅作用于该子进程，不更改机器或用户的永久策略。在允许执行本地脚本的当前 PowerShell 中，也可以：

```powershell
. .\scripts\dev-env.ps1
java -version
javac -version
mvn --version
```

这里 dot-source 的前导 `. ` 不能省略，作用是让环境留在当前终端；关闭终端后自然失效。后续实际构建优先走 `scripts/maven.ps1`，便于使用仓库内依赖缓存。

新克隆或清理本地工具后，通过固定配置重建：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup-toolchain.ps1
```

如果校验过的 ZIP 已在 `.tools/downloads/`，可追加 `-Offline`；缺少有效包时明确失败，不偷偷切换版本。在线获取需网络允许。本轮已通过离线重复运行验证：复用已校验文件、不重新解压、不联网，版本检查仍成功；也验证了新 PowerShell 子进程从其他目录调用 Maven 入口。
