# 交付与演示

本项目是 Windows x64 桌面 C/S 课程演示，包含独立买家端和服务端管理窗口、SQLite 持久化及原生 TCP 请求应答。无真实支付或退货物流。交付补充材料与六篇历史报告分开维护。

UI24/UI25已确认并实现。两套主题、商品卡片、事件通知、轮询、已读/关联跳转及公告发布均接通；完整离线verify 422项通过。S15最终ZIP与干净源码重建结果见最终交付验收，用户实际接受仍待试用。

## 在源码仓库构建

首次执行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup-toolchain.ps1` 准备固定工具。再执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\maven.ps1 --batch-mode --no-transfer-progress verify
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\release.ps1 -Offline
```

首次获取依赖需联网，缓存完整后可离线。release 再执行完整 verify，通过后使用固定 JDK 的 jlink 生成运行环境，并打包两个独立 shaded JAR、说明、可重建源码与 SHA256SUMS.txt。包位于源码仓库的 dist，每次新建唯一目录，不清理旧包；source 为显式目录白名单，不带运行数据库、账号会话、待核对记录、源码目录的本地配置或 Maven 缓存。打包和解压验证细节见最终交付验收。

## 运行交付包

解压整个 ZIP 到可写目录，可含中文和空格。以下命令在解压后的 merchant 目录执行；两个终端分别运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\run.ps1 -App server
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\run.ps1 -App client
```

交付包已含 Windows x64 Java 运行环境，无需另装 JDK/Maven。服务端先出现管理员登录入口，买家端允许游客看商品；管理退出回登录，只有关闭服务端程序才停止买家服务。两端默认仅连接本机 127.0.0.1:18765；改端口时两端命令同加 `-Port 18766`，不开放外网。

源码仓库中对应的启动命令是 `scripts/start.ps1`，参数相同。修改源码必须先构建，再完全关闭两个旧进程后重启；退出账号不会加载新 JAR。

## 主流程演示

1. 服务端登录管理员，买家游客看商品，然后买家 A 登录。A 加入商品、调整卡内数量；买家 B 的购物车保持独立。
2. 管理端为商品配置直降和统一折扣，填写覆盖当前北京时间的起止、启用；先预览再保存。买家刷新看真实报价。100 元先减 10 再九折为 81 元，两件 162 元；舍入逐件执行。
3. 管理端新建券草稿并发布；买家购物车领券、手选一张或不用券。按商品优惠后已选金额判断门槛，最低零元。暂停领取不废已领券，发布后条款锁定。
4. 在购物车取消某一条勾选，核对已选合计，点击准备并明确二次确认模拟成交。库存、订单、用券和已选条目同事务变化；未选条目保留。我的订单展示历史商品和原实付，不按现价重算。
5. 买家在订单详情填写原因申请整单退货；管理端先拒绝并说明，再让买家重新申请。查看历史，管理员批准后尚未退款，明确完成才模拟退款原实付并补原数量一次。原券不返还。
6. 查看买家消息与未读状态，管理端发布优惠公告；另一账号阅读状态独立。消息跳转本人订单或关联商品，重新登录后状态保留。
7. 在设置中切换两套主题并重启检查偏好，核对购物车、历史金额和售后状态不变。

## 异常与恢复

- 成交或售后提交超时不等于失败。按界面“核对本次”查询，允许手动用原键重试；不要删除 data/client-pending 或 data/client-returns，也不要换新购买/申请。
- 本地核对文件损坏会保留文件并阻止对应的新提交；先查本人订单及服务端记录。退出登录不清理待核对记录。
- 库存、车版本或报价变化会要求刷新/重确认；券明确不可用时自动切不用券并提示，新金额仍须明确确认。
- 服务端重启后重新登录。先检查包的 SHA256SUMS.txt 与 ZIP 旁的 SHA256，确认两个程序来自同一次构建。
- 界面显示“版本不支持”时，两端全部关闭并用同一交付包启动，不混用旧 JAR。

## 材料与边界

源码仓库保留六篇 DOCX 历史报告；包内 source/reports 和 source/docs 保留报告、实现架构与UML、需求、并发与异常验收及售后验收材料，最终交付验收在本轮收尾补充。文档中“自动验证通过”与“用户实际接受界面”分别记录，不以截图代替完整手动体验。

本轮不加入注册、真实支付/物流、商品上传、多店、聊天、退出后系统通知、公网部署或可靠消息中间件。可选统计未实现，不影响同步事务主线。用户已明确券排除商品属于后续扩展，本轮保持全店券。

Java 运行环境来自 Eclipse Temurin，原始法律说明保留于 runtime/legal。运行依赖为 Gson、SQLite JDBC 及其传递依赖，third-party按实际运行JAR元数据保存原始POM及可用的许可证/NOTICE，避免shade同名文件覆盖；完整依赖版本和来源可由源码仓库 pom.xml、scripts/toolchain.json 及 Maven dependency:tree 检查。
