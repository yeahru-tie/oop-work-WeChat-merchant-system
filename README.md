## 阅读与维护

Markdown 文档可直接在 GitHub 或支持 Markdown 的编辑器中阅读；DOCX 报告请下载后使用 Microsoft Word 或 WPS 打开。

修改报告时更新对应的正式文件，通过 Git 记录版本。编辑器配置、Office 临时文件、缓存和本地会话资料不纳入版本管理。

文本文件使用 UTF-8 编码及 LF 换行；DOCX 文件按二进制文件管理。
